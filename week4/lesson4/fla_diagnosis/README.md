# FLA / GDN 数值排查留存

实验日期：2026-10-12 至 2026-10-13。本文合并原各轮报告；按用户要求删除本轮测试代码、JSON、补丁副本与临时缓存。保留生产实现、模型、环境和其他课程材料。

## 结论与当前路线

目前不能认定 FLA 可以安全替代现有 Qwen3.5-4B GDN 核心。合成测试的高精度诊断版本通过，不等于真实模型全层通过。最后一次消融解决了一个真实输入样例，但没有完成全层回归或端到端验证。

正式引擎保持 HF chunk prefill / 现有单 token decode 路径，不改变状态池 dtype，不合入实验 FLA 修改。继续课程；后续优化另行建立验证门槛。

## 问题与实验设计

问题是：相同 Q/K/V、门控和历史状态下，FLA 与参考实现的最终 recurrent state 存在差异，可能影响后续 token。不能只比较当轮 output，也不能把 HF 当作绝对真值。

三方比较：HF chunk、FLA chunk、独立 FP32 逐 token recurrence。后者按衰减历史、预测、计算 beta 加权残差、外积更新、Q 读取状态执行；不引入 BF16 中间存储，输出比较时统一舍入。FP32 参考仍有浮点误差。

- 共享外部归一化 Q/K，关闭内部归一化；统一 scale、布局、dtype、初始状态。
- 检查输入未被修改、形状、有限值、output 和最终 state。
- 合成输入：16 组，覆盖 B=1、T=1/7/64/65/128、无初始状态/FP32/BF16 初始状态，另有 B=2、T=7、FP32 状态。
- 探索性阈值：output atol=0.002、rtol=0.02；state atol=0.001、rtol=0.01；相对 L2≤0.01。不是已经验证的模型质量标准。
- 数值实验与性能实验分开，不能把隔离核心收益写成端到端加速。

## 排查过程

| 实验 | 主要发现 |
|---|---|
| 统一外部 Q/K 归一化 | 差异仍存在，排除仅由归一化路径不同解释全部问题 |
| 加入 FP32 recurrence | 合成测试 HF state 16/16 通过，原版 FLA 3/16；两者 output 均 16/16 |
| 三角求解 TF32→IEEE | 合成输入改善有限，部分变差，没有改变通过数 |
| A 中间存储 BF16→FP32 | 合成输入改善有限，没有改变通过数；必须控制消费端 dtype/计算方式 |
| w/u 写回 | w 单独影响小；u 保留 FP32 对多 token state 误差改善约 12.58%–18.82%，仍 3/16 |
| V×beta 中间舍入 | 单独保留 FP32 改善约 15.38%–19.20%；与 u 联合后改善约 37.36%–41.29%，5/16 |
| 衰减后的残差写回 BF16 | 与 V×beta、u FP32 联合后，相对基础版本 state 误差降低约 92.71%–96.15%，合成测试 output/state 均 16/16 |

这些百分比对应各轮特定对照，不应相加作误差来源占比。高精度诊断版本仍含其他 BF16 中间值，并非全 FP32。

## 真实模型输入：不能由合成结果外推

捕获 24 个 GDN 层的实际核心输入：整段 65 token、64+64 分块的首块、带真实 BF16 历史状态的续块，共 72 组。候选共享固定输入，候选输出不反馈到下一层或下一步，因此这是核心重放，不是模型端到端验证。

| 路径 | output 通过 | state 通过 |
|---|---:|---:|
| HF chunk | 72/72 | 72/72 |
| 原版 FLA | 72/72 | 43/72 |
| V×beta / u / 残差 FP32 诊断版 | 72/72 | 50/72 |

诊断版 72 组 state 相对 L2 均改善，但逐元素门槛仍有 8 组新增通过、1 组退步。整体误差下降不保证每个元素更接近参考。

## 最后一次有界收尾实验

选择零起始层号 21、首个 64-token 块、初始 state=None。共享输入哈希与上一轮一致。以已有高精度诊断版为基础，统一 A 的消费端后，做 A 存储精度 × 三角求解精度的 2×2 消融。

| 路径 | state 相对 L2 | state 最大绝对误差 | state 通过 |
|---|---:|---:|---|
| 原诊断版 / 匹配对照 | 0.00659110071 | 0.0124372840 | 否 |
| 仅 A FP32 | 0.00532735605 | 0.00946491957 | 否 |
| 仅求解 IEEE | 0.00163174351 | 0.00405430794 | 否 |
| A FP32 + 求解 IEEE | 5.07886227e-7 | 1.66893005e-6 | 是 |

HF 同输入 state 相对 L2 为 5.73344e-7。所有分支 output 通过；组合分支 output 相对 L2 仍为 0.003057923，并非逐位一致。

解释：只提高计算精度，写回 BF16 仍会损失信息；只提高存储精度，也可能保存了低精度计算的误差。此真实样例中两者共同修改才通过，说明合成输入上不敏感的环节在真实输入上仍可能关键。

证据只覆盖这一个样例，不能把此前 50/72 改写成 72/72，不能宣称完全解决 FLA 适配。

## 课程下一步

1. 掌握请求生命周期：Prefill→Decode，完成/取消/失败后的 KV 与 state 回收。
2. 理解请求隔离、逻辑 token 位置与物理 slot、chunk 边界历史状态延续。
3. 若重新推进 FLA：先恢复真实全层回归，再验证候选自身状态反馈、连续 decode、完整层/logits，最后测精度修改的性能和显存成本。

关键方法：先固定输入和契约，再找首个差异点；一次只改变明确环节，控制 dtype 连锁变化；同时观察 output/state；将局部数值证据、端到端正确性和性能收益分别表述。
