## A. 框架掌握（本周必须）

面试耦合附加项（2026-10-01）：每课完成3分钟独立复述及一道反例；结课必须说明自己的改动、上游能力、AI协助和未验证范围，不能背生成的说明替代现场源码解释。跨周C++/算子/通信验收见[面试计划](../INTERVIEW_PLAN.md)，不要求现在全部完成。

- [ ] 10分钟内画出请求→调度→执行→采样→回收，并定位真实函数。
- [ ] 独立完成完整Prefill加两次Decode的计数题，说明停止前后缓存计数差别。
- [ ] 根据短代码推导waiting/running和token budget变化，解释当前本地chunking限制。
- [ ] 计算逻辑token位置对应物理KV slot，并区分recurrent state slot。
- [ ] 给出[A,B]→[B,A]的完整映射，conv/recurrent、KV、长度和输出归属均不串用。
- [ ] 找出Qwen3.5至少6个适配点，说明模型加载、采样和EOS也在适配范围内。
- [ ] 亲自完成一项小修改（trace、计数或状态映射），先观察相关失败测试，再修复；不是只运行助手交付代码。
- [ ] 至少讲清4项正式vLLM差别，每项有固定版本入口；不得把本地上游已有prefix caching/chunked prefill列为新增成果。
- [ ] 解释InferLab机制层、编排层、产物层，并指出步数指标与GPU实测时间的区别。

漏项就针对该项补课，不宣称全面掌握vLLM生产系统。
